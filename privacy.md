# Privacy Policy

Last updated: September 2026

## Overview

BepInEx Android Launcher ("the app") is an open-source application developed by NextBep. This privacy policy explains what data the app accesses and how it is used.

## Data Collection

The app does **not** collect, transmit, or share any personal data. All data processing occurs locally on your device.

### Network Access

The app accesses the internet solely to:
- Download BepInEx framework files
- Download .NET runtime
- Download unstripped libunity.so files
- Check for app updates

No personal information, usage statistics, or analytics are sent to any server.

### Storage Access

The app requires **All files access** permission to:
- Extract BepInEx framework files to game directories
- Manage mod files and modpacks
- Copy game resources for modding support

All files are stored locally on your device. No files are uploaded or transmitted externally.

### Logcat Access

The app may read logcat output for diagnostic purposes when:
- A game crashes and you choose to export diagnostics
- You manually request diagnostic export from Settings

Logcat data is only processed locally and is only shared if you explicitly choose to export and share it.

## Third-Party Services

The app does not integrate any third-party analytics, advertising, or tracking services.

## Open Source

The app is open-source under the GPL-3.0 license. You can review the full source code on [GitHub](https://github.com/NextBep/BepInEx.Android.Launcher).

## Changes to This Policy

If this privacy policy is updated, the changes will be posted in the GitHub repository and reflected in the next app release.

## Contact

For questions about this privacy policy, please open an issue on [GitHub](https://github.com/NextBep/BepInEx.Android.Launcher/issues).
