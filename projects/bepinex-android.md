# BepInEx.Android

BepInEx mod framework for Android Unity IL2CPP games.

## Overview

BepInEx.Android brings the BepInEx modding framework to Android, targeting Unity games built with the IL2CPP scripting backend.

## Repository

[github.com/NextBep/BepInEx.Android](https://github.com/NextBep/BepInEx.Android)

## Features

- Injection support for Unity IL2CPP games
- Plugin loading and management
- Harmony patching for runtime code modification
- Config file generation and management
- BepInEx compatibility layer for Android
