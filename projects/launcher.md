# BepInEx Android Launcher

The launcher app for managing BepInEx on Android.

## Overview

A Material You themed launcher that provides game detection, BepInEx framework extraction, and mod management for Unity IL2CPP games.

## Repository

[github.com/NextBep/BepInEx.Android.Launcher](https://github.com/NextBep/BepInEx.Android.Launcher)

## Features

- **Game Detection** - Auto-scan installed Unity IL2CPP games
- **One-Tap Launch** - Launch games with BepInEx injected
- **Modpack Management** - Create, activate, import/export modpacks
- **Config Editor** - Built-in config editor with syntax highlighting
- **Crash Detection** - Automatic crash detection with diagnostic export
- **Multi-language** - 18 language support
- **Material You** - Dynamic colors with Android 12+ Monet support
- **Unstripped LibUnity** - Automatic download of debug libunity for stack traces
