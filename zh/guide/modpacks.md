# 整合包管理

整合包允许你将多个 Mod 组合在一起，并轻松切换不同的 Mod 组合。

## 创建整合包

1. 进入 **整合包** 标签页
2. 点击 **+** 按钮
3. 输入名称和可选描述
4. 选择要包含的 Mod
5. 点击 **创建**

整合包将出现在你的列表中，可以随时激活。

## 导入整合包

整合包使用 `.rhp` 或 `.zip` 格式进行共享。

1. 进入 **整合包** 标签页
2. 点击 **导入** 按钮
3. 从设备中选择 `.rhp` 或 `.zip` 文件
4. 整合包将被导入并出现在你的列表中

::: tip
你可以导入朋友分享的整合包或从社区来源下载的整合包。
:::

## 导出整合包

1. 长按整合包
2. 选择 **导出**
3. 选择保存 `.rhp` 文件的位置
4. 与他人分享文件

## 激活整合包

1. 进入 **整合包** 标签页
2. 点击整合包以选择它
3. 整合包将被激活，其 Mod 将在下次启动时加载

一次只能激活一个整合包。激活新的整合包将停用之前活动的整合包。

## 停用整合包

1. 进入 **整合包** 标签页
2. 点击当前活动的整合包以取消选择

当没有活动整合包时，游戏将不加载任何整合包 Mod 启动。

## 浏览 Mod 文件

启动器包含内置文件浏览器，用于查看 Mod 文件：

1. 选择整合包
2. 点击 **浏览文件**
3. 导航文件树
4. 点击文本文件以查看或编辑它们
5. 使用带语法高亮的编辑器编辑配置文件

## 配置编辑器

内置配置编辑器支持：

- **JSON** 语法高亮
- **Lua** 语法高亮
- 实时编辑，带未保存更改指示器
- 退出时自动保存

编辑配置文件：

1. 在文件浏览器中导航到文件
2. 点击 `.json` 或 `.lua` 文件
3. 进行修改
4. 点击 **保存**

## 图标管理

每个整合包可以有自定义图标：

1. 长按整合包
2. 选择 **设置图标**
3. 从设备中选择图片
4. 图标将显示在整合包列表中

要移除图标，长按整合包并选择 **移除图标**。

## 桌面快捷方式

你可以创建主屏幕快捷方式，直接使用特定整合包启动游戏：

1. 长按整合包
2. 选择 **创建快捷方式**
3. 选择要关联的游戏
4. 快捷方式将出现在你的主屏幕上

点击快捷方式将直接使用关联的整合包启动游戏。
