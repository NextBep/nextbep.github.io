# 安装

## 系统要求

- Android 9+（API 28+）
- arm64-v8a 设备
- 已安装 Unity IL2CPP 游戏

## 安装步骤

1. 从 [GitHub Releases](https://github.com/NextBep/BepInEx.Android.Launcher/releases) 下载最新 APK
2. 打开 APK 文件并安装
3. 按提示授予 **所有文件访问** 权限
4. 启动器将自动扫描已安装的 Unity IL2CPP 游戏

## 存储权限

BepInEx 启动器需要所有文件访问权限来：
- 解压 BepInEx 框架文件
- 管理 Mod 文件和整合包
- 复制游戏数据以支持 Mod
