# 配置

BepInEx 启动器提供每个游戏和通用设置来自定义行为。

## 每个游戏的设置

每个游戏都有自己独立的设置。选择一个游戏进行配置。

### 未剥离的 libunity

某些游戏需要未剥离的 `libunity.so` 才能使某些 Mod 正常工作。此设置是每个游戏的：

- **启用**（默认）：下载并使用未剥离的 `libunity.so`
- **禁用**：使用游戏原始的 `libunity.so`

要清除下载的 libunity 缓存，请转到 **设置 → 清除 libunity 缓存**。

### 阻止 Unity Kill

默认情况下，启动器不阻止 `UnityPlayer.kill()`。某些游戏可能需要阻止此操作以防止关闭时崩溃。

- **启用**：阻止 `UnityPlayer.kill()` 调用
- **禁用**（默认）：允许正常关闭行为

## 通用设置

### 动态颜色（Material You）

在 Android 12+ 上，启动器使用系统的动态颜色（Monet）来为应用主题着色。

- **启用**（默认）：使用系统动态颜色
- **禁用**：使用默认的青绿色主题（#00897B）

### 动画

开启或关闭 UI 动画。禁用动画可以在较旧的设备上提高性能。

- **启用**（默认）：整个 UI 中的平滑过渡
- **禁用**：无动画以实现更快的交互

## 调试设置

### 导出诊断

如果游戏崩溃，启动器将检测到并提供导出诊断信息。这包括：

- Logcat 输出
- BepInEx 日志文件
- 系统信息

你也可以从 **设置 → 导出诊断** 手动导出诊断信息。

### 日志查看器

访问内置日志查看器检查 BepInEx 输出：

1. 转到 **设置 → 查看日志**
2. 浏览或过滤日志条目
3. 根据需要复制或共享日志

详情请参阅[日志查看器](./log-viewer.md)。

## 更新

启动器在启动时会自动检查更新。你也可以在 **设置 → 关于** 中手动检查。

当有可用更新时：
1. 弹出对话框显示发行说明
2. 点击 **下载** 获取最新版本
3. 安装 APK 进行更新
