# 故障排查

BepInEx 启动器常见问题和解决方案。

## 游戏无法启动

### 检查系统要求

- Android 9+（API 28+）
- arm64-v8a 设备
- Unity IL2CPP 游戏（非 Mono）

### 授予权限

确保启动器拥有 **所有文件访问** 权限：
1. 转到 Android 设置 → 应用 → BepInEx 启动器
2. 点击 **权限**
3. 启用 **所有文件访问**

### 启用 libunity

某些游戏需要未剥离的 `libunity.so`：
1. 在启动器中转到游戏设置
2. 启用 **使用未剥离的 libunity**
3. 尝试重新启动

## Mod 未加载

### 验证整合包

1. 确保整合包在 **整合包** 标签页中已激活
2. 检查 Mod 是否与你的游戏版本兼容
3. 查看 BepInEx 日志中的错误消息

### 检查日志

1. 打开启动器
2. 转到 **设置 → 查看日志**
3. 查找与 Mod 加载相关的错误消息

### 常见 Mod 问题

| 问题 | 解决方案 |
|------|----------|
| Mod 未检测到 | 确保 Mod DLL 在正确的 BepInEx/plugins 文件夹中 |
| 缺少依赖项 | 安装 Mod 所需的依赖项 |
| 版本不匹配 | 更新 Mod 以匹配你的游戏版本 |

## 启动时崩溃

### 检查系统要求

- Android 9+（API 28+）
- arm64-v8a 设备
- Unity IL2CPP 游戏（非 Mono）

### 清除数据

如果游戏启动时崩溃：
1. 转到 **设置 → 清除 BepInEx**
2. 转到 **设置 → 清除 .NET**
3. 尝试重新启动

### 启用 libunity

某些游戏需要未剥离的 `libunity.so`：
1. 转到游戏设置
2. 启用 **使用未剥离的 libunity**
3. 尝试重新启动

## BepInEx 解压失败

### 清除 BepInEx 缓存

1. 转到 **设置 → 清除 BepInEx**
2. 重新启动游戏 - 启动器将重新解压框架

### 检查存储空间

确保有足够的存储空间：
- BepInEx 框架：约 50 MB
- .NET 运行时：约 30 MB
- 未剥离的 libunity：因游戏而异

## libunity 下载缓慢

### 检查网络连接

- 确保有稳定的网络连接
- 尝试在 Wi-Fi 和移动数据之间切换

### 清除 libunity 缓存

1. 转到 **设置 → 清除 libunity**
2. 尝试重新启动 - 启动器将重新下载

## CoreCLR 启动失败

此错误表示 .NET 运行时初始化失败：
1. 转到 **设置 → 清除 .NET**
2. 重新启动游戏
3. 如果问题持续，请检查设备兼容性

## 华为 / HarmonyOS

如果在华为设备上遇到旋转崩溃：
- 启动器包含 HarmonyOS 旋转问题的内置修复
- 如果问题持续，请尝试在设备设置中禁用自动旋转

## 获取帮助

如果仍有问题：
1. 从 **设置 → 导出诊断** 导出诊断信息
2. 访问 [GitHub Issues](https://github.com/NextBep/BepInEx.Android.Launcher/issues) 页面
3. 在问题报告中附上诊断文件
