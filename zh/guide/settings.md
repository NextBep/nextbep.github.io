# 设置

设置页面允许你自定义启动器的外观和行为。

## 外观

### 主题

在浅色和深色主题之间选择，以符合你的偏好。

- **浅色**：简洁明亮的界面
- **深色**：在低光环境下更护眼

### 语言

启动器支持 18 种语言。从下拉菜单中选择你偏好的语言。

如果你的语言缺失或不完整，请考虑在 [Crowdin](https://crowdin.com/project/bepinex-android-launcher) 上贡献翻译。详情请参阅[翻译指南](./translations.md)。

### 动态颜色（Material You）

在 Android 12+ 上，启动器可以使用系统的动态颜色（Monet）来为应用主题着色。

- **启用**（默认）：使用基于壁纸的系统动态颜色
- **禁用**：使用默认的青绿色主题（#00897B）

### 动画

开启或关闭 UI 动画。

- **启用**（默认）：整个 UI 中的平滑过渡和动画
- **禁用**：无动画 - 可以在较旧或较慢的设备上提高性能

## 游戏内

这些设置影响启动器在游戏运行时的交互方式。

### 浮动日志

一个小型覆盖日志窗口，在游戏运行时显示 BepInEx 输出。

- **启用**：在游戏过程中显示可拖动的浮动日志窗口
- **禁用**（默认）：无覆盖 - 退出游戏后查看日志

你可以点击浮动日志来展开它，拖动以重新定位，或使用关闭按钮关闭它。

### 未剥离的 libunity

某些游戏需要未剥离的 `libunity.so` 才能使某些 Mod 正常工作。

- **启用**（默认）：为游戏下载并使用未剥离的 `libunity.so`
- **禁用**：使用游戏原始的已剥离 `libunity.so`

这是每个游戏的设置。详情请参阅[配置](./configuration.md)。

### 阻止 Unity Kill

某些游戏调用 `UnityPlayer.kill()` 来关闭，这可能导致 Mod 卸载问题。

- **启用**：阻止 `UnityPlayer.kill()` 调用以防止意外关闭
- **禁用**（默认）：允许正常关闭行为

仅在游戏关闭期间出现崩溃时启用此选项。

## 维护

这些工具帮助保持启动器和 Mod 环境的清洁。

### 清除 BepInEx

移除所有游戏的已解压 BepInEx 框架文件。启动器将在下次启动时重新解压它们。

在以下情况使用：
- BepInEx 文件损坏
- 你想要强制重新安装框架
- 在包含新 BepInEx 版本的启动器更新之后

### 清除 .NET

移除已下载的 .NET 运行时文件。启动器将在下次启动时重新下载它们。

在以下情况使用：
- .NET 运行时损坏
- 你想要释放存储空间
- 在运行时更新之后

### 清除 libunity

移除所有已下载的未剥离 `libunity.so` 文件。启动器将在需要时在下次启动时重新下载它们。

在以下情况使用：
- 未剥离的 libunity 导致崩溃
- 你想要释放存储空间
- 你怀疑文件损坏

### 复制资源

将游戏资源复制到 BepInEx Mod 可访问的位置。这对于需要直接读取游戏资源的 Mod 非常有用。

在以下情况使用：
- Mod 报告缺少游戏资源
- 你想要启用基于资源的 Mod 功能
