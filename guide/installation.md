# Installation

## Requirements

- Android 9+ (API 28+)
- arm64-v8a device
- A Unity IL2CPP game installed

## Steps

1. Download the latest APK from [GitHub Releases](https://github.com/NextBep/BepInEx.Android.Launcher/releases)
2. Open the APK file and install it
3. When prompted, grant **All files access** permission
4. The launcher will automatically scan for installed Unity IL2CPP games

## Storage Permission

BepInEx Launcher needs access to all files to:
- Extract BepInEx framework files
- Manage mod files and modpacks
- Copy game data for modding support
